# Miso

Altijd iets lekkers op de planning. Weekmenu, boodschappen en samen lekker eten.

- `ios/` SwiftUI-app (`brew install xcodegen && cd ios && xcodegen`)
- `backend/` FastAPI-backend: recepten (website, tekst, foto), Allerhande, weekmenu, AH-boodschappen
- `assets/` logo, mascotte en ander beeldmateriaal
- `docker-compose.yml` start de backend op poort 9927 (`APP_PIN`, `ANTHROPIC_API_KEY`, `DATA_DIR`)
